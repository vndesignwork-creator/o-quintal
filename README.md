# O Quintal

Site estático do restaurante O Quintal, na Amadora. Inclui a versão atual com as correções de contraste no menu e na legenda da fotografia.

## Publicação

O GitHub Pages publica o site a cada commit na branch `main`. Nas definições do repositório, GitHub Pages usa **Deploy from a branch**, branch **main**, pasta **/ (root)**.

O site usa HTML, CSS e JavaScript, sem dependências de instalação. Os caminhos relativos permitem a publicação num subdiretório do GitHub Pages.

## Conteúdo

As reservas abrem o contacto telefónico do restaurante. A ementa aponta para o site original. Confirmar a ementa e os horários com o restaurante antes de os atualizar.
